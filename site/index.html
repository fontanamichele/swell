Swell

A minimal browser with fully isolated spaces in one window.

Each space has its own cookies, site storage, history, saved passwords, form data, extensions and permissions. Sign in to two accounts of the same site side by side, and delete a space to delete everything it kept. Built on Gecko, with an Arc-style sidebar. No telemetry, no accounts, open source (MPL 2.0).

Download the latest alpha

macOS 11 or later on Apple silicon (disk image), or Linux (a tarball: unpack it and run ./install.sh). Windows later.

Opening the alpha

The alpha is for developers and curious users, and it is not signed or notarized yet, so macOS asks you to confirm it the first time:

  1. Open the downloaded disk image and drag Swell to Applications.
  2. In Applications, right-click Swell and choose Open, then press Open again.
  3. If macOS still refuses, run this once in Terminal: 
    xattr -dr com.apple.quarantine /Applications/Swell.app

Beta builds will be signed. You can verify the download with the checksum published next to it on the release page.

What works, what does not

  • Spaces, a sidebar of favorites, pinned tabs and folders, a command bar, import from Arc.
  • Passwords, addresses, cards, downloads, camera, microphone and add-ons per space.
  • Not yet: sync, Windows, Save Page As, a history view, other languages.

Found a problem? Open an issue. Security reports: see the security policy.
